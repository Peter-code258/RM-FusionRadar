# 多传感器融合处理中心子系统 (feature/multi-sensor-fusion)

雷达系统核心融合中枢，实现多源目标数据的时间同步、空间对齐、数据关联与状态融合。采用传感器级后融合架构。

## 技术栈
- C++17、Eigen3、nlohmann/json、原生 UDP Socket

## 核心架构
- **后融合架构**：各传感器数据独立输入，仅在数据层融合，模块间完全解耦、故障隔离
- **三级坐标转换链**：传感器坐标系 → 雷达站车体坐标系 → 赛场世界坐标系（4×4 变换矩阵）
- **时间同步**：硬件时间戳 + 线性插值对齐；10Hz SDR 数据通过卡尔曼预测补全中间时刻
- **数据关联**：匈牙利匹配算法，欧氏距离为匹配代价，阈值 1.0m
- **动态加权融合**（按目标距离自动切换）：
  - 近距离 <8m：视觉 0.7 / 雷达 0.3
  - 中距离 8-15m：视觉 0.5 / 雷达 0.5
  - 远距离 >15m：视觉 0.2 / 雷达 0.8
  - SDR 权重 0.9，修正系统长期漂移
- **三级降级容错**：视觉失效→纯雷达+SDR；雷达失效→单目视觉；全部感知失效→SDR 纯数据模式

## 关键特性
- 目标置信度管理：低于阈值自动移除，避免幽灵目标
- 统一数据格式：唯一 ID、世界坐标、速度向量、置信度、目标类别、时间戳
- 故障自动检测：传感器数据超时自动判定故障，无缝触发降级
- 统一目标列表 UDP 输出，可直接下发给作战单位

## 编译运行
```bash
mkdir build && cd build
cmake .. && make -j
./fusion_center ../config/fusion_config.yaml
```
