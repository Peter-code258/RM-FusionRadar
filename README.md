# 无人机跟踪与反制子系统 (feature/anti-drone-tracking)

空中目标检测跟踪与激光反制控制模块，采用二级跟踪架构。

## 技术栈
- C++17、OpenCV4、Eigen3、ESKF 误差状态卡尔曼、串口通信

## 二级跟踪架构
1. **粗跟踪**：广角相机全局画面检测无人机，输出像素坐标，控制云台转动将目标移入视野中心
2. **精跟踪**：切换小范围 ROI，亚像素级精确定位无人机中心；ESKF 估计三维运动轨迹，预测下一帧位置

## 核心特性
- **ESKF 误差状态卡尔曼滤波**：估计三维运动轨迹，预测下一帧位置
- **前馈控制**：加入目标运动前馈量，补偿伺服系统跟随延迟
- **光斑检测闭环**：接入光斑检测数据，实时修正激光指向偏差
- **光轴标定**：支持激光光轴与相机视轴的同轴度标定补偿
- **激光反制逻辑**：跟踪稳定度达标后触发激光发射，支持持续照射计时与有效反制判定
- **多源融合**：支持接入激光雷达测距数据，融合无人机三维坐标
- **伺服控制**：输出云台/振镜控制量，对接下位机 1kHz 电流闭环控制接口

## 编译运行
```bash
mkdir build && cd build
cmake .. && make -j
./anti_drone_tracker ../config/anti_drone_config.yaml
```

## 运行测试

```bash
cd build && make -j && ./test_anti_drone
```
