# 激光雷达点云感知子系统 (feature/lidar-pointcloud-perception)

独立的激光雷达目标检测与跟踪模块，纯 C++17 实现，可单独运行，也可接入融合中心。

## 技术栈
- C++17、PCL 1.12+、Eigen3、nlohmann/json、CMake

## 处理流水线
```
原始点云 → 直通滤波 → 体素下采样 → RANSAC地面分割 → 八叉树欧式聚类 → 卡尔曼滤波跟踪 → 结构化目标输出
```

## 核心特性
- **直通滤波**：X[-8,8]m、Y[-15,15]m、Z[0.1,2.0]m，参数可配置
- **自适应体素下采样**：默认 0.05m，目标距离 >15m 自动放宽至 0.08m
- **RANSAC 地面分割**：距离阈值 0.08m，迭代 100 次；仅对 Z<0.5m 区域拟合提升速度
- **欧式聚类**：八叉树加速，动态聚类半径 `0.35 + 0.012 * distance`，过滤 [15, 800] 点聚类
- **目标跟踪**：匈牙利匹配 + 常速卡尔曼滤波，最大匹配距离 0.5m，丢失容忍 3 帧
- **静态障碍物过滤**：导入场地固定障碍物坐标模板，按位置匹配剔除
- **多雷达拼接接口**：支持外参矩阵，将双雷达点云统一到世界坐标系

## 编译运行
```bash
mkdir build && cd build
cmake .. && make -j
./lidar_perception ../config/lidar_config.yaml
```

## 运行测试
```bash
cd build
make -j && ./test_lidar
```

## 配置文件
`config/lidar_config.yaml` 包含所有可调参数：滤波范围、体素分辨率、RANSAC 阈值、聚类参数、跟踪参数、静态障碍物、多雷达外参等。

## 输出
标准 `Target` 结构（含唯一 ID、世界坐标、速度、置信度、3D 包围盒），可通过 UDP 发布到融合中心。
