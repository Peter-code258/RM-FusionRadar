# 低成本单目视觉雷达子系统 (feature/mono-vision-radar)

零激光雷达的纯单目全局定位系统，百元硬件成本实现基础雷达功能。

## 技术栈
- C++17、OpenCV4、Eigen3、nlohmann/json

## 处理流水线
```
相机畸变校正 → 目标检测结果接入 → 地面接触点提取 → 单应性矩阵映射 → 卡尔曼跟踪 → 全局坐标输出
```

## 核心特性
- **相机内参**：导入内参矩阵与畸变系数，完成径向畸变校正
- **场地标定**：输入至少 8 组「像素坐标-世界坐标」对应点，RANSAC 求解单应性矩阵 H
- **目标映射**：YOLO 检测框底部中心点为地面接触点，单应性矩阵转换为世界二维坐标
- **盲区跟踪**：导入场地障碍物几何模型，目标进入盲区时卡尔曼滤波维持轨迹预测
- **目标重识别**：目标离开盲区重新出现时，自动匹配原有 ID，不发生 ID 切换
- **距离补偿**：远距离目标投影偏差修正系数
- **分区标定**：支持场地分区标定，提升远距离定位精度
- **相机姿态校验**：内置姿态偏差检测，相机晃动超阈值自动告警

## 编译运行
```bash
mkdir build && cd build
cmake .. && make -j
./mono_radar ../config/mono_config.yaml
```

## 标定工具
```bash
./calibration_tool <field_image>
```
交互点击标记点，自动计算单应性矩阵。

## 运行测试
```bash
cd build && make -j && ./test_mono
```
